Definition of Done
------------------

The following MUST be true before any coding task may be considered done:

- All new code MUST be DRY and SOLID compliant.
- All new code MUST be covered with new unit tests.
- All CSharpier and .editorconfig styles MUST be respected.
- All projects MUST compile without warnings.
- New unit tests MUST pass.

Unit Tests
----------

The following MUST be true for all new unit tests.

- All unit test projects MUST use MSTest.
- All unit tests SHOULD use FluentAssertions wherever possible.
- All new test code MUST be DRY and SOLID compliant, within the test project and across projects.
- All CSharpier and .editorconfig styles MUST be respected.
- All projects MUST compile without warnings.
- New unit tests MUST pass.
